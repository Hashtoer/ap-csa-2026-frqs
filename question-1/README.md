Part A:
I first created an integer variable (j) in order to store the appending successive integers. If I had not done this, the username would have been a lot of 1's after the end of the username instead of the intended result of successive intergers. 
After that, as long as the username was not available, I kept increasing the integer value at the end of username until it was available.

Part B: 
For the getShortenedName method, I used a while loop to check if there is a hyphen in the username. While there is a hyphen, I found the index of the hyphen, then I used substring to add the username before the hyphen, and the username after the hyphen. We keep repeating this until there is no longer a hyphen.
